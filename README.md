# Aurora Broker Client Dashboard

Responsive React/Vite dashboard inspired by the supplied reference screenshots, with a distinct violet/lavender visual identity.

## Run

```bash
npm install
npm run dev
```

Open the URL shown by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Features

- Responsive collapsible sidebar, navigation across 10 screens
- Dashboard with balance chart, account switching, overview widgets
- Accounts, funding requests, statements, rewards, games, referrals, profile, support and onboarding
- Light/dark mode, notification panel, mobile layout, interactive demo controls
- Sample data only. No backend, authentication, payment processing or actual PDF generation is connected.
